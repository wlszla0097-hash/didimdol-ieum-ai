# 이음24 — 참여에서 채용까지

> 국민취업지원제도·청년도전지원사업에 참여한 청년의 이력을 **AI가 채용 언어로 바꿔** 공고와 잇고,
> 기업은 면접 전에 **‘지원제도 활용 가능’ 표시**를 본인 동의 하에 확인하며,
> 채용이 확정되면 **근로계약 점검과 신청 시기 알림**까지 이어지는 고용서비스 웹 MVP

- **배포 URL**: https://didimdol-ieum-ai-zeta.vercel.app
- **서비스 기획서**: [docs/service-plan.md](docs/service-plan.md)
- **스크린샷**: [docs/screenshots/](docs/screenshots/)
- 2026 고용24 국민참여 AI 고용서비스 발굴 해커톤 아이디어 기획안의 MVP 범위를 구현한 시제품입니다. **모든 인물·공고·지원자는 합성 데이터**입니다.

## 1. 서비스 소개

| 화면 | 이용자 | 기능 | AI |
|---|---|---|---|
| **구직자** `#seeker` | 국취·청년도전 참여 청년 | ① 참여 이력 불러오기 → ② AI 직무 역량 문장·자기소개 초안, 맞춤 공고 추천 → ③ 표시 동의·지원 | ✅ |
| **기업** `#employer` | 중소기업 인사담당자 | ④ 공고 점검(정규직·규모·소재지·최저임금·체불 명단) → ⑤ 지원자 확인(표시만, 사유·연령 비공개) → ⑥ 채용 확정 시 근로계약 점검·신청 알림 | ✅ |
| **주무관** `#officer` | 고용센터 담당자 | ⑦ 참여 이력 근거·지침 조항·기업 요건·계약 점검·고용유지 기간이 정리된 신청 건 (판정 없음, 결정은 주무관) | – |
| 지원사업 진단 `#diagnose` | 기업 (확장 2단계) | 공공서비스(혜택) 정보에서 다음 지원사업과 연계 로드맵 | ✅ |
| 홈 / 안내 | 모두 | 서비스 흐름, FAQ, 데이터 출처, 연동 상태 | – |

### 설계 원칙: "판단은 규칙엔진과 사람, AI는 번역과 설명"
- **표시 판단은 규칙엔진**: 2026년 청년일자리도약장려금 지침 1-3항(취업애로청년)을 코드로 옮겼습니다.
  - 수도권 기업: 국민취업지원제도 참여(수급자격 인정 + 취업활동계획 수립) 후 **최초 취업**, 또는 청년도전지원사업 **수료**인 청년이면 표시 대상
  - 비수도권 기업: 취업애로 요건이 없으므로 지원자별 표시 대신 **공고 단위로 안내**
  - 정규직이 아니거나 우선지원대상기업이 아닌 공고에는 표시하지 않음
- **차별 방지**: 기업 응답에는 표시 여부(true/false)만 담고, 참여 사업·연령은 담지 않습니다. 지원자 목록은 지원일 순서로 고정하며 표시 기준 정렬·필터 기능이 없습니다. 사유는 **채용 확정 후 신청 단계에서 본인 동의가 있을 때만** 신청 건에 붙습니다.
- **AI 출력 검증(서버)**:
  - 후보에 없는 공고 id는 제거합니다.
  - 지원금·장려금·연령 언급, 입력에 없던 숫자가 나온 문장은 차단하고 기본 문장으로 바꿉니다. 화면에 "차단 N건"을 표시합니다.
- **AI 없이도 동작**: AI 키가 없거나 AI가 실패해도 규칙 기반 결과(공고 추천·표시·점검)는 그대로 나옵니다.

## 4. 환경 변수(키) 설정

API 키는 **코드·README·스크린샷에 절대 넣지 않고** 환경 변수로만 관리합니다.

| 이름 | 필수 | 설명 |
|---|---|---|
| `GEMINI_API_KEY` | 둘 중 하나 | [Google AI Studio](https://aistudio.google.com/apikey)에서 발급 |
| `ANTHROPIC_API_KEY` | 둘 중 하나 | [Claude Console](https://console.anthropic.com/settings/keys)에서 발급. 둘 다 있으면 Claude 우선 |
| `AI_MODEL` | 선택 | 모델 바꾸기. 기본값 Claude `claude-haiku-4-5-20251001`, Gemini `gemini-flash-latest` |
| `WORK24_KEY` | 선택 | 고용24 OpenAPI 인증키. 없으면 합성 공고로 동작 |
| `WORK24_BASE_URL` | 선택 | 고용24 채용정보 엔드포인트 (승인 후 개발명세서 주소가 다르면 지정) |
| `DATA_GO_KR_KEY` | 선택 | 공공데이터포털 인증키(Decoding). 지원사업 진단 화면용 |

- **로컬**: `.env.example`을 복사해 `.env`를 만들고 값을 채웁니다 (`.gitignore`에 포함).
- **Vercel**: Project → Settings → Environment Variables에 등록한 뒤 **재배포**합니다.
- **키가 유출됐다면**: 발급처에서 즉시 폐기·재발급하고 Vercel 값을 바꾼 뒤 재배포합니다.

## 5. 실행 방법

```bash
python dev_server.py          # http://127.0.0.1:3000
python -m pytest tests        # 테스트 (pip install pytest)
```

## 6. 시연 시나리오 (3분)

1. **구직자**: '김하늘(국취 참여·훈련 수료)'을 고르고, 표시 동의를 체크한 뒤 [AI로 이력 정리 · 공고 추천]을 누릅니다.
   - 역량 문장, 자기소개 초안, 추천 공고가 나옵니다.
   - 수도권·정규직·우선지원대상 공고에만 ‘✓ 지원제도 활용 가능’이 표시됩니다.
   - 대기업 공고에는 표시되지 않습니다.
2. 첫 공고에서 [이 공고에 지원(시연)]을 누르면 기업 화면으로 이어집니다.
   - 공고 점검 결과와 지원자 목록이 나옵니다.
   - 내 지원서에는 표시만 보이고, 사유와 나이는 보이지 않습니다.
3. 내 지원서에서 [채용 확정]을 누르고 근로계약 점검을 실행합니다.
   - [오류 있는 예시로 바꾸기]를 누르면 위반 의심 항목과 AI 설명이 나옵니다.
   - 6개월 고용유지 시점과 알림일이 표시됩니다.
   - 이때 처음으로 신청 근거(참여 이력)가 공개됩니다.
4. [주무관 확인 화면으로 보내기]를 누르면 근거·지침 조항·확인 항목이 정리된 신청 건이 나옵니다.
   - 처리 버튼은 주무관이 직접 누릅니다.
   - 판정은 자동으로 하지 않습니다.

비교용 인물:
- '박지민': 국취 참여 중 취업 이력이 있어 '최초 취업'이 아니므로 표시하지 않습니다.
- '최유나': 일반 훈련만 받았으므로 표시하지 않습니다.
- '이서준': 청년도전 수료로 표시합니다. 비수도권 공고에서는 공고 단위로 안내합니다.

| AI 출력 검증 실패 | 해당 문장만 기본 문장으로 대체하고 "차단 N건" 표시 |

| 고용24·공공데이터 실패 | 합성 공고·예시 데이터로 자동 전환, 화면에 출처 표시 |

## 8. 한계와 다음 단계
- 표시와 점검은 **예상 안내**입니다. 지침의 모든 요건(감원·중복지원 제한 등)을 다 옮기지 않았고, 최종 확인은 고용센터가 합니다.
- 고용24 OpenAPI는 이용 승인 전이라 합성 공고로 시연합니다. 승인 후 개발명세서에 맞춰 `core/work24.py`의 항목 매핑을 확인해야 합니다.
- 화면 간 시연 상태는 브라우저 메모리에만 있어 새로고침하면 초기화됩니다 (개인정보를 남기지 않기 위함).
- 확장: 2단계 기업 지원사업 진단(구현됨, 미리보기) → 3단계 서류 표준화(AI 전처리) → 4단계 고용24 회원·행정 시스템 연계.
