# 서비스 기획서 — 지원사업 이음 AI

## 1. 서비스 개요

| 항목 | 내용 |
|---|---|
| 서비스명 | 지원사업 이음 AI |
| 한 줄 소개 | 공공데이터와 AI로 우리 회사가 받을 수 있는 고용지원사업과 '다음 단계'를 안내하고, 근로계약 조건을 1차 점검하는 웹 서비스 |
| 목적 | ① 고용지원사업 진입 허들 낮추기 ② 지원사업 간 연계 공백 줄이기 ③ 계약서 기본 요건 확인 시간 단축 |
| 배경 | 기획자는 중소기업 고용지원금 신청을 실무에서 지원하며, 기업이 "우리가 대상인지", "다음에 무엇을 받을 수 있는지"를 몰라 지원을 놓치는 사례를 반복해서 봤다. |

## 2. 타겟 사용자

| 사용자 | 상황 | 얻는 가치 |
|---|---|---|
| 직원 5~99인 중소기업 대표·인사담당자 (주 타겟) | 채용·정규직 전환·유연근무 도입을 계획 중이지만 지원사업 요건을 잘 모름 | 3분 안에 해당 가능성이 높은 사업과 확인할 요건, 연계 순서를 파악 |
| 노무·인사 컨설턴트 | 고객사 상담 전 빠른 1차 진단이 필요 | 상담 준비 시간 단축, 계약서 1차 점검 |

## 3. 페이지 구성 (해시 메뉴 이동, 상단 메뉴 + 모바일 햄버거 메뉴)

| # | 섹션 | 주소 | 내용 |
|---|---|---|---|
| 1 | 홈 | `#home` | 서비스 소개, 3가지 문제와 해결 방법, 설계 원칙 |
| 2 | AI 기업 진단 | `#diagnose` | 기업 정보 입력 폼 → AI 추천·로드맵 결과 |
| 3 | 지원사업 찾기 | `#programs` | 공공데이터 기반 사업주 대상 지원사업 목록·검색 |
| 4 | 근로계약 점검 | `#check` | 근로조건 입력 → 규칙 점검 + AI 쉬운 설명 |
| 5 | 서비스 안내 | `#about` | 동작 방식, FAQ, 데이터 출처, 연동 상태 |

반응형 기준: 900px 이하에서 입력·결과를 세로로 배치, 720px 이하에서 햄버거 메뉴와 1열 입력칸. 보너스로 다크 모드를 제공한다.

## 4. 핵심 기능

### 기능 ① AI 기업 진단 (`POST /api/diagnose`)

| 구분 | 내용 |
|---|---|
| 입력 | 업종(필수), 상시근로자 수(필수), 지역, 올해 계획 체크(청년 채용·정규직 전환·유연근무 등 8종 중 1개 이상 필수), 현재 참여 사업, 추가 설명(500자 이하) |
| 처리 | ① 공공데이터에서 사업주 대상 사업 조회 → ② 계획 키워드로 후보 최대 12개 선별(규칙) → ③ AI가 후보 안에서 추천·로드맵 작성 → ④ 서버가 후보에 없는 id 제거, 사업명·링크는 원본으로 교체 |
| 출력 | 상황 요약, 추천 사업 최대 5개(적합도 높음/보통/확인 필요, 이유, 확인할 요건, 지금 할 일, 공공데이터 원문), 연계 로드맵 최대 4단계, 추가로 필요한 정보 |
| 사용자 가치 | 수백 쪽 지침을 읽지 않고도 "무엇을, 어떤 순서로" 확인할지 알 수 있음 |

### 기능 ② 근로계약 1차 점검 (`POST /api/check`)

| 구분 | 내용 |
|---|---|
| 입력 | 고용 형태, 임금 형태, 계약 시작·종료일, 기본급(필수), 고정수당, 주 소정근로시간(필수), 1일 소정근로시간, 휴게시간, 필수 기재사항 체크 |
| 처리 | 규칙 엔진이 최저임금(주휴 포함 월 환산), 법정근로시간, 휴게시간, 기간제 계약기간, 필수 기재사항을 판정 → AI는 판정 결과만 쉬운 말로 설명하고 수정 제안 |
| 출력 | 항목별 판정(위반 의심/확인 필요/적정)과 근거 조문, AI 요약·항목별 설명·수정 제안 |
| 사용자 가치 | 계약서의 기본 법적 요건을 바로 확인하고 고칠 점을 이해 |

### 기능 ③ 지원사업 찾기 (`GET /api/programs`) — AI 미사용
공공데이터 원문을 검색어로 필터링해 카드로 보여 준다.

## 5. AI 기능의 입력·출력·실패 처리 기준

### 입력 기준
- 필수값: 진단(업종, 규모, 계획 1개 이상), 점검(기본급, 주 소정근로시간). 프론트와 서버에서 모두 검사.
- 길이 제한: 업종 40자, 추가 설명 500자, 요청 본문 20KB.
- 개인정보 입력 금지 안내(성명·주민번호).

### 출력 기준 (할루시네이션 방지)
- AI 응답은 정해진 JSON 형식만 허용하고, 해석 실패 시 오류로 처리.
- 추천·로드맵의 사업 id가 후보 목록에 없으면 서버가 버리고 개수를 화면에 표시("검증 제외 N건").
- 사업명·기관·링크·원문은 공공데이터 값으로 표시(AI 문장 사용 안 함).
- 점검 설명은 규칙 엔진 결과에 있는 항목만 표시.
- 모든 결과에 "참고용, 최종 자격은 소관기관 확정" 문구 표시.

### 실패 처리 기준

| 상황 | 기준 | 안내 문구 |
|---|---|---|
| 빈 입력 | 필수값 누락 | "필수값을 입력하세요: (항목)" + 입력칸 강조 |
| API 오류 | AI 4xx/5xx → 서버 502/503 | "AI 서비스 오류가 발생했습니다. 잠시 후 다시 시도하세요. (오류 코드)" |
| 지연 | 응답 8초 초과 | "AI 응답이 평소보다 늦어지고 있어요" |
| 타임아웃 | 서버 25초 / 브라우저 45초 | "응답 시간이 초과되었습니다…" |
| 키 미설정 | 환경 변수 없음 | "AI 기능이 아직 설정되지 않았습니다" |
| 과다 요청 | IP당 1분 10회 초과 | "요청이 너무 많습니다. 1분 후 다시 시도하세요" |
| 공공데이터 실패 | 키 없음·호출 실패 | 예시 데이터로 자동 전환, "예시 데이터" 표시 |
| AI 설명만 실패 | 점검 기능 | 규칙 점검 결과는 그대로 표시하고 AI 설명 실패만 안내 |

### 테스트 입력/결과 예시

| 구분 | 입력 | 기대 결과 |
|---|---|---|
| 정상 | 제조업 / 5~29인 / 청년 채용 + 정규직 전환 | 청년 채용·정규직 전환 관련 사업 추천과 로드맵 표시 |
| 빈 입력 | 업종 비움 | "필수값을 입력하세요: 업종" |
| 긴 입력 | 추가 설명 500자 | 정상 처리 (500자 초과는 입력 불가) |
| 계약 점검 | 기간제 / 월 200만원 + 수당 10만원 / 주 40시간 / 휴게 30분 / 종료일 없음 | 최저임금·휴게·계약기간 위반 의심, AI 설명 표시 |
| AI 오류 | AI 서버 500 | 오류 안내 + 오류 코드 |

## 6. 비용·운영 고려
- 빠르고 저렴한 모델(Claude Haiku 또는 Gemini Flash)을 기본값으로 사용, 응답 길이 제한.
- 공공데이터는 6시간 캐시해 호출 수를 줄임.
- IP당 요청 제한과 입력 길이 제한으로 과금 남용 방지.
