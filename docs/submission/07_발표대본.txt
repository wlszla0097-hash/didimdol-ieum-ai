1. 서비스 소개 (30초)  [홈 화면]
────────────────────────────────────────
"저는 고용지원금 신청과 근로계약 검토 실무를 하면서,
정부 취업지원 프로그램을 수료한 청년의 이력이 채용으로 이어지지 않는 것을 자주 봤습니다.

'이음24'는 국민취업지원제도·청년도전지원사업 참여 이력을 AI가 채용 언어로 정리해 공고와 잇고,
기업에는 본인 동의 하에 '채용 시 활용 가능한 정부지원제도가 있다'는 표시만 보여 주는 서비스입니다.

이용자는 구직자, 기업 인사담당자, 고용센터 주무관 세 부류이고,
상단 메뉴로 홈·구직자·기업·주무관·안내 섹션을 오갑니다."
  → 과제 기준: 섹션 3개 이상 + 메뉴 이동

────────────────────────────────────────
2. AI 기능 시연 (1분 30초)  [구직자 → 기업 → 채용 확정]
────────────────────────────────────────
[구직자: '예시 불러오기' → 동의 체크 → AI로 이력 정리]
"구직자가 경험을 자유롭게 쓰면, AI가 활동별 표, 직무 역량 문장, 자기소개 초안을 만들고
실제 공고 목록 안에서만 맞는 공고를 추천합니다."

[결과 아래 '서버 검증으로 차단된 문장 N건' 가리키기]
"AI가 원문에 없는 숫자나 지원금·나이 같은 내용을 쓰면 서버가 그 문장을 막습니다.
지원제도 표시 판단은 AI가 아니라 지침을 옮긴 규칙 코드가 합니다."

[이 공고에 지원 → 기업 화면]
"기업 화면에서는 AI가 공고를 정리하고, 지원자는 핵심 포인트만 먼저 보입니다.
참여 사업명과 나이는 채용 전에는 보이지 않습니다."

[채용 확정 → 오류 있는 예시로 바꾸기 → 근로계약 점검]
"근로계약은 규칙이 최저임금·근로시간·휴게를 점검하고, AI는 그 결과를 쉬운 말로 설명합니다."
  → 과제 기준: AI API 연동 (입력 → 결과 출력)

3. 실패 처리 (20초)  [구직자에서 빈칸으로 버튼 클릭]

"필수값이 비면 '필수값을 입력하세요'와 함께 칸이 빨갛게 표시되고, 서버도 한 번 더 검사합니다.
AI 오류는 오류 코드와 함께, 8초가 넘으면 '늦어지고 있어요', 45초가 넘으면 시간 초과를 안내합니다.

5. 구조 설명 — HTML·CSS·JS / fetch / 서버리스 (1분)  [README 6장 또는 코드]
────────────────────────────────────────
"HTML은 화면의 뼈대, CSS는 모양과 반응형·다크 모드, JavaScript는 메뉴 이동·입력 검사·서버 호출·결과 표시를 맡습니다.

버튼을 누르면 app.js가 입력을 검사하고 fetch('/api/seeker')로 JSON을 보냅니다.
Vercel이 api/seeker.py를 서버리스 함수로 실행합니다.
서버리스 함수는 서버를 따로 켜 두지 않고, 요청이 올 때만 실행되는 백엔드 코드입니다.
이 함수가 규칙으로 공고를 고르고, AI를 부르고, 결과를 검증해서 JSON으로 돌려주면
app.js가 화면에 카드로 그립니다.
api/ 폴더의 파일 하나가 주소 하나가 되고, 함수들이 함께 쓰는 코드는 core/ 폴더에 따로 뒀습니다."
  → 과제 목표: 역할 설명, fetch 흐름, Serverless 구조

6. API 키 관리 (20초)  [README 4장]
────────────────────────────────────────
"API 키는 코드에 넣지 않고 Vercel 환경 변수에만 등록합니다.
브라우저는 /api 주소만 부르고 키는 서버 함수 안에서만 쓰기 때문에, 개발자 도구로도 보이지 않습니다.
키가 코드에 들어가면 GitHub에 공개되어 누구나 과금을 일으킬 수 있으니,
유출되면 즉시 폐기·재발급하고 커밋 이력도 정리해야 합니다."
  → 과제 목표: 환경 변수로 키를 관리하는 이유

7. 로컬 vs 배포, 오류 해결 경험 (1분)  [docs/ai-coding-log.md]
────────────────────────────────────────
"로컬에서는 .env와 dev_server.py로 돌리고, 배포는 GitHub에 push하면 Vercel이 자동으로 다시 배포합니다.
환경 변수를 바꾸면 Redeploy를 해야 반영됩니다.

AI 코딩 도구로 만들었지만 오류는 직접 원인을 찾았습니다. 대표적으로 세 가지입니다.
 ① AI 키를 넣었는데 401 인증 실패 → 키 형식만 보여 주는 진단 화면을 만들어 보니
    교육용 중계 서버 전용 키였고, 접속 주소 환경 변수를 추가해 해결했습니다.
 ② AI가 최저임금 기준 월급을 '215만 원'으로 틀리게 썼습니다(실제 2,156,880원)
    → 점검 결과에 없는 숫자는 서버가 막도록 가드를 넣었습니다.
 ③ 모바일에서 카드가 잘림 → 화면보다 넓은 요소를 찾아보니 선택 상자 때문이었고, CSS로 고쳤습니다.
전체 9건을 증상·원인·수정 순서로 정리해 두었습니다."
  → 과제 목표: 로컬/배포 차이, 수정·재배포 흐름, 오류 원인 설명

예상 질문과 짧은 답
════════════════════════════════════════
Q. requirements.txt가 비어 있는데요?
A. 파이썬 표준 라이브러리(urllib, json)만 써서 설치할 패키지가 없습니다. 그 이유를 파일에 적어 뒀습니다.

Q. 🔒 내부 메뉴는 왜 잠겨 있나요?
A. 실제 고객사 정보를 다루는 제 업무용 진단 기능이라 비밀번호로 잠갔습니다. 과제의 AI 기능은 구직자·기업 화면에서 모두 확인할 수 있습니다.

Q. 공고와 인물은 진짜 데이터인가요?
A. 모두 가상(합성) 데이터입니다. 고용24 채용정보 API 연동 코드는 있지만 이용 승인 전이라 합성 공고로 동작하고, 화면에 출처를 표시합니다.

Q. AI가 틀리면요?
A. 추천은 실제 공고 목록 안에서만 허용하고, 원문에 없는 숫자·금지 표현은 서버가 막습니다. 표시 판단과 계산은 코드가 하고, 최종 확인은 고용센터라고 안내합니다.

Q. 개인정보는요?
A. 서버에 저장하지 않습니다. 필수·선택 동의를 나눴고, AI 서버로 전송된다는 점(처리 위탁·국외 이전)도 고지합니다. AI 동의가 없으면 AI로 보내지 않습니다.

Q. 비용은 얼마나 드나요?
A. Claude Haiku 기준 구직자 1명당 약 40원으로 추산했습니다. 기업 화면은 구직자가 만든 결과를 다시 쓰기 때문에 AI를 다시 부르지 않습니다.
